# 安全设计

## 本地数据

- 会话、消息、附件与配置保存在应用私有存储（Room + 应用私有目录）。
- `allowBackup=false`，并通过 `dataExtractionRules` 排除 root、file、database、sharedpref 与外部目录，禁用系统云备份与设备间自动迁移。
- 卸载、清数据或换机会丢失本地记录；当前 Alpha 不提供完整备份或迁移。

## 凭据保护

- API Key 使用 Android Keystore 派生的 AES-256-GCM 密钥加密，密文形如 `v1:<iv>:<ct>`，保存在应用私有偏好中。
- 界面只显示掩码；保存新值会替换旧值，不提供明文回显。
- 解密失败与“从未保存”区分显示，避免把不可读误判为未配置。

## 网络边界

Disper 没有自建服务器。网络访问只有两类：

1. **用户主动发起的模型请求**：仅在点击发送时，将完成该请求所需的消息与附件内容发送到用户配置的模型服务商；服务商如何处理数据由其隐私政策决定。
2. **GitHub 更新检查**：匿名请求公开 Releases 元数据（版本号、说明、链接），不携带聊天、附件、配置、API Key、设备标识或 Token。

仓库为 Private 时，匿名更新检查返回不可用，这是预期行为；不会因此声称“已是最新”。

## 文件与工作区权限

- 自定义目录通过系统 SAF 选择器授权，权限由系统持久化；授权失效时需重新选择。
- 工具调用只允许读取当前会话绑定工作区内的 UTF-8 TXT/md，并受轮次、调用次数与体积上限约束。
- 模型不能写入、覆盖、删除文件。

## 执行能力限制

当前只提供只读工具轮次；没有任意 Shell / Python 执行、无障碍自动操作、悬浮窗控制、Root 或跨应用自动化。

## 尚未实现的高级权限

无障碍服务、悬浮窗、通知、电话/短信、应用启动控制等能力未实现，也未申请对应权限。

## 漏洞与安全问题报告

请优先使用 GitHub 仓库的私密漏洞报告入口：**Security → Report a vulnerability**（GitHub Security Advisory）。该入口不会公开内容。

如果该入口不可用，请通过仓库维护者已公开的私下联系方式沟通；不要在公开 Issue 中粘贴 API Key、Token、设备日志或其他敏感信息。
